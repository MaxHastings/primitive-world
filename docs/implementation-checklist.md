# Implementation review

The [core direction](direction.md) is the design contract. Verify physical
accounting, local sensing, paid unrewarded plasticity, CPU/GPU mutation parity,
whole-record hereditary replacement, fresh newborn lifetime state, observation
isolation, checkpoint continuation and explicit engine limits.

Run [CONTRIBUTING.md](../CONTRIBUTING.md) checks. They establish implementation
integrity, not intelligence or ecological adaptation. Use [long-run testing](long-run.md)
for uninterrupted operation. Wallpaper composition, monitor changes and desktop
input routing still require testing on the actual desktop.
